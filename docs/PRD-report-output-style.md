## 1. 문제 정의

### 현재 상태: "개발자 디버그 뷰"
```
[Score Gauge] → [카테고리 바 차트] → [보너스/패널티 카드] → [벤치마크 단가 테이블] → [보정계수] → [범례]
```
- 단가(원/㎡) 기준 비교 — 소비자가 이해 불가
- 편차율(%) 중심 — "내가 얼마 더 내는지" 직관적이지 않음
- 합계 없음 — 전체 그림이 안 보임
- 소비자 행동 유도 섹션 없음 (협상 가이드, 결제 스케줄 등)

### 목표 상태: 설계서 "소비자 재무 보디가드 리포트"
```
[1. 종합 요약] → [2. 적정가 비교표] → [3. 주요 발견] → [4. 비용 절감 포인트]
→ [5. 경고 배너들] → [6. 카테고리별 분석] → [7. 안전 결제 스케줄]
→ [8. 보너스/패널티] → [9. 보정계수] → [10. 데이터 출처 푸터]
```
- **총액(원)** 기준 비교 — "4,200,000원 vs 3,850,000원, 350,000원 비쌈"
- **합계 행** — "전체 42,000,000원 중 2,450,000원 절감 가능"
- **소비자 행동 유도** — 결제 스케줄, 데이터 출처

## 3. 섹션별 출력 스타일 상세

### 3.1 종합 요약 (Section 1) — 재구현

**현재**: ScoreGauge + 가중합산/보너스/패널티 숫자 3개
**설계서 스타일**:
```
┌─────────────────────────────────────────────────┐
│  [고객명]님의 견적 분석 결과                       │
│  [아파트 정보]                                    │
│                                                   │
│  ┌──────────┐  총 견적 금액: 42,000,000원         │
│  │  Score   │  적정 시장가:  39,550,000원         │
│  │  Gauge   │  시장 대비:    +5.8% (약간 높음)    │
│  │   72점   │                                     │
│  └──────────┘  면허 확인: ⚠️ 미확인               │
│                                                   │
│  💰 절감 가능 금액: 2,450,000원                    │
└─────────────────────────────────────────────────┘
```

**추가 데이터 필요**:
- 전체 견적 총액 = Σ(item.original_total_price 또는 unit_price × quantity)
- 전체 적정가 총액 = Σ(item.adjusted_benchmark_price × quantity) — 벤치마크 있는 항목만
- 차이 = 견적 총액 - 적정가 총액

### 3.2 적정가 비교표 (Section 11) — 핵심 재구현

**현재 (단가 기준)**:
```
카테고리 | 항목명 | 견적 단가 | 벤치마크 | 보정 후 | 편차(%)
욕실     | 타일    | 45,000   | 38,000  | 42,000 | +7.1%
```

**설계서 스타일 (총액 기준)**:
```
┌────────────────┬──────────────┬──────────────────┬────────────┬────────┐
│ 항목           │ 현재 견적가   │ 적정가(벤치마크) │ 차이(원)    │ 판정   │
├────────────────┼──────────────┼──────────────────┼────────────┼────────┤
│ 바닥재         │  4,200,000   │  3,850,000       │ +350,000   │ 약간높음│
│ 욕실 공사      │  8,500,000   │  8,200,000       │ +300,000   │ 적정   │
│ 주방 공사      │  6,800,000   │  7,100,000       │ -300,000   │ 양호   │
│ ...            │              │                  │            │        │
├────────────────┼──────────────┼──────────────────┼────────────┼────────┤
│ 합계           │ 42,000,000   │ 39,550,000       │+2,450,000  │ B      │
└────────────────┴──────────────┴──────────────────┴────────────┴────────┘
  * 보정계수(면적/지역/계절/등급) 적용 후 산출
  💰 ROI: 절감 가능 금액 2,450,000원
```

**핵심 변경점**:
1. **단가 → 총액**: `original_total_price` (또는 unit_price × quantity) vs `adjusted_benchmark_price × quantity`
2. **편차(%) → 차이(원)**: 소비자가 바로 이해하는 금액 단위
3. **합계 행**: 전체 견적 vs 전체 적정가
4. **ROI 배지**: "절감 가능 금액: X원"
5. **차이 색상**: 양수(빨강=비쌈) / 음수(파랑=적정이하) / 0 근방(초록)

**데이터 계산**:
```typescript
// 각 항목의 총액 비교
const quoteTotal = item.original_total_price
  || (item.original_unit_price && item.original_quantity
      ? item.original_unit_price * item.original_quantity
      : null)

const fairTotal = item.adjusted_benchmark_price && item.original_quantity
  ? item.adjusted_benchmark_price * item.original_quantity
  : null

const diff = quoteTotal && fairTotal ? quoteTotal - fairTotal : null
```

### 3.3 주요 발견 (Section 3) — 신규

**설계서 스타일**: 긍정 / 부정 / 주의 3컬럼 카드

```
┌─────────────────┬──────────────────┬──────────────────┐
│ ✅ 긍정          │ ⚠️ 부정          │ 🔍 주의          │
├─────────────────┼──────────────────┼──────────────────┤
│ 모든 항목에      │ 3건의 미분류     │ 바닥재 수량이     │
│ 수량/단위 명시   │ 항목 존재        │ 면적 대비 부족    │
│ (+5점 보너스)   │ (-15점 패널티)   │ (추가비용 주의)   │
│                 │                  │                  │
│                 │ 면허 미확인      │ 2건의 "현장 후    │
│                 │ (-15점 패널티)   │ 확정" 조건부 항목 │
└─────────────────┴──────────────────┴──────────────────┘
```

**데이터 매핑**:
- 긍정 = `scoreBreakdown.bonuses` → 자연어 변환
- 부정 = `scoreBreakdown.penalties` 중 일반 패널티
- 주의 = `penalties` 중 경고성 (`under_quantity`, `over_quantity`, `site_confirm`, `dump_risk`)

### 3.4 비용 절감 포인트 (Section 4) — 신규

**설계서**: "구체적 금액과 대안"

```
┌─────────────────────────────────────────────────┐
│ 💰 비용 절감 포인트                               │
├─────────────────────────────────────────────────┤
│ 1. 바닥재 → 적정가 기준 350,000원 절감 가능       │
│    현재 4,200,000원 → 적정 3,850,000원            │
│                                                   │
│ 2. 목공 → 적정가 기준 280,000원 절감 가능         │
│    현재 3,280,000원 → 적정 3,000,000원            │
│                                                   │
│ ────────────────────────────────────             │
│ 총 절감 가능 금액: 630,000원                       │
└─────────────────────────────────────────────────┘
```

**데이터**: 적정가 비교표에서 `diff > 0`(비싼 항목)만 추출, 금액 내림차순 정렬

### 3.5 리스크 알림 (Section 8) — 보강

**현재 구현**: 덤핑 위험 배너, 과소산량 배너
**추가 필요**:
- 면허 미확인 경고 (현재 패널티에만 있고 배너 없음)
- "현장 후 확정" 조건부 경고 (신규)
- 계절 프리미엄 안내 (season factor ≠ 1.0일 때)

## 8. 성공 기준
