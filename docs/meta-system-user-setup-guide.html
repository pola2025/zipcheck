Meta 시스템 사용자 + 앱 구성 가이드

Instagram + Threads 자동 게시를 위한 설정

시스템 사용자란? 개인 계정에 의존하지 않고 서버(Cloudflare Workers)에서 API를 호출할 수 있는 전용 계정입니다. 토큰이 만료되지 않아 자동화에 적합합니다.

진행 체크리스트

1

사전 준비

Instagram 비즈니스 계정 확인

Instagram 앱 → 프로필 → 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환

이미 비즈니스/크리에이터 계정이면 건너뜁니다.

Facebook 페이지 연결 확인

Instagram 설정 → 계정 센터 → 프로필 → Facebook 페이지 연결

"집첵" Facebook 페이지가 없으면 새로 생성 후 Instagram과 연결합니다.

Threads 계정 확인

Instagram 계정으로 Threads 가입이 되어 있어야 합니다.

2

Meta 비즈니스 포트폴리오 생성

시스템 사용자는 비즈니스 포트폴리오(구 비즈니스 관리자) 안에서만 생성할 수 있습니다.

Meta Business Suite 열기 →
business.facebook.com → 설정 (톱니바퀴) → 비즈니스 설정

이미 비즈니스 포트폴리오가 있다면 이 단계를 건너뛰세요. 비즈니스 설정 → 비즈니스 정보에서 비즈니스 ID를 확인할 수 있습니다.

비즈니스 ID 기록

3

Meta 앱 생성

Meta for Developers - 앱 생성 →

3-1. 앱 유형 선택

"비즈니스" 유형 선택
(Other → Business 또는 직접 "비즈니스" 선택)

3-2. 앱 정보 입력

앱 이름 ZipCheck Auto Publisher
앱 연락처 이메일 imagime2002@naver.com
비즈니스 포트폴리오 Step 2에서 생성한 포트폴리오 선택

3-3. 앱 ID 기록

3-4. 앱 시크릿 기록

앱 대시보드 → 설정 → 기본 설정 → 앱 시크릿 코드 (표시)

앱 시크릿은 절대 공개하지 마세요. Cloudflare Workers Secret으로만 저장합니다.

4

Instagram + Threads API 제품 추가

앱 대시보드 → 제품 추가

추가할 제품 2개

Instagram Graph API

"설정" 클릭 → Instagram 계정 연결

Threads API

"설정" 클릭 → Threads 계정 연결

필요한 권한 (Permissions)

Instagram

  • instagram_basic
  • instagram_content_publish
  • instagram_manage_insights
  • pages_show_list
  • pages_read_engagement

Threads

  • threads_basic
  • threads_content_publish
  • threads_manage_insights
  • threads_manage_replies

앱 모드: 처음에는 "개발 모드"입니다. 시스템 사용자는 개발 모드에서도 테스트 가능하지만, 실서비스용으로는 "라이브 모드"로 전환 + 앱 검수가 필요합니다.

5

시스템 사용자 생성

비즈니스 설정 - 시스템 사용자 →
비즈니스 설정 → 사용자 → 시스템 사용자 → 추가

시스템 사용자 정보

이름 zipcheck-publisher
역할 관리자 (Admin)

콘텐츠 게시에 관리자 권한 필요

참고: "직원" 역할로는 콘텐츠 게시 권한이 부족할 수 있습니다. Instagram content_publish에는 관리자(Admin) 시스템 사용자를 권장합니다.

6

에셋 할당 + 액세스 토큰 생성

6-1. 에셋 할당

생성한 시스템 사용자를 선택한 후 "에셋 할당" 클릭

1 페이지 → 집첵 Facebook 페이지 선택 → "콘텐츠 관리" 권한
2 Instagram 계정 → 집첵 Instagram 선택 → "콘텐츠 관리" 권한
3 앱 → ZipCheck Auto Publisher 앱 선택 → "앱 관리" 권한

6-2. 액세스 토큰 생성

시스템 사용자 선택 → "새 토큰 생성" 클릭

앱 선택: ZipCheck Auto Publisher

체크할 권한:

토큰은 한 번만 표시됩니다! 반드시 복사해서 안전한 곳에 저장하세요.

시스템 사용자 토큰 = 영구 토큰
일반 사용자 토큰과 달리 만료되지 않습니다. Cloudflare Workers Secret으로 저장하면 됩니다.

7

API 테스트

7-1. 토큰 유효성 확인

터미널 
curl "https://graph.facebook.com/v21.0/me?access_token=YOUR_TOKEN"

시스템 사용자 이름과 ID가 반환되면 성공

7-2. Instagram 계정 ID 확인

터미널 
curl "https://graph.facebook.com/v21.0/me/accounts?access_token=YOUR_TOKEN"

Facebook 페이지 목록이 반환됩니다. 페이지 ID로 Instagram 계정 ID를 조회:

터미널 
curl "https://graph.facebook.com/v21.0/{PAGE_ID}?fields=instagram_business_account&access_token=YOUR_TOKEN"

7-3. Threads 사용자 ID 확인

터미널 
curl "https://graph.threads.net/v1.0/me?access_token=YOUR_TOKEN"

Cloudflare Workers에 저장할 Secrets

터미널 (프로젝트 루트에서 실행) 
wrangler secret put META_APP_ID
wrangler secret put META_APP_SECRET
wrangler secret put META_ACCESS_TOKEN
wrangler secret put META_IG_ACCOUNT_ID
wrangler secret put META_THREADS_USER_ID
