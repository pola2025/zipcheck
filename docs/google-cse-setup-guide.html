Google Custom Search Engine 설정

ZipCheck 시장가 크롤러에 필요한 2가지 키를 설정합니다

진행 체크리스트

1

Custom Search API 활성화

경로: Google Cloud Console → API 및 서비스 → 라이브러리

Custom Search API 페이지 열기 →

주의: 기존 ZipCheck 프로젝트(GA4 연동 중인)를 선택하세요.

무료 한도: 100회/일 (크롤러는 1회 실행에 최대 10회 사용)

2

API 키 생성

경로: API 및 서비스 → 사용자 인증 정보 → + 사용자 인증 정보 만들기 → API 키

사용자 인증 정보 페이지 열기 →

API 키 제한 설정 (권장):

  • 애플리케이션 제한사항: 없음 (Workers에서 호출하므로 IP 제한 불필요)
  • API 제한사항: Custom Search API만 선택
3

Custom Search Engine 생성

검색 엔진 만들기 페이지 열기 →

설정 값:

검색 엔진 이름ZipCheck Market Price
검색 대상전체 웹 검색
언어한국어
지역한국

중요: 생성 후 → 설정 → 검색 엔진 ID(cx) 복사

형식: a1b2c3d4e5f6g7h8i

4

Wrangler 시크릿 등록 명령어

위에서 입력한 값으로 명령어가 자동 생성됩니다

위의 API 키와 CX를 입력하면 명령어가 생성됩니다
