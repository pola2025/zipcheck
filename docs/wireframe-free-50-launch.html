6 백엔드 API 변경

NEW: GET /api/quote-requests/free-slots

무료 분석 잔여 수 조회 (public)
// Response
{
  "total": 50,
  "used": 12,
  "remaining": 38,
  "is_open": true       // remaining > 0
}
구현: SELECT COUNT(*) FROM quote_requests WHERE is_free_promo = true

MODIFY: POST /api/quote-requests/submit

1. 요청 body에 is_free_promo: true 필드 추가
2. is_free_promo=true일 때:
- free promo 카운트 확인 (50명 초과 시 429 반환)
- payment 관련 필드 NULL 허용
- paid_amount = 0, payment_status = 'free_promo'
3. quantity = 1 고정 (다중 비교 비활성)

UNCHANGED: 분석 엔진

- POST /admin/:id/auto-analyze → 그대로 동작
- runAutoAnalysis() → 변경 없음
- analyses + analysis_items 테이블 → 변경 없음
- 관리자 분석 워크플로우 → 완전 동일

7 DB 변경사항

quote_requests 테이블 — 컬럼 추가 1건

-- 무료 프로모션 플래그
ALTER TABLE quote_requests
ADD COLUMN IF NOT EXISTS is_free_promo BOOLEAN DEFAULT false;

-- 인덱스 (카운트 쿼리 최적화)
CREATE INDEX IF NOT EXISTS idx_quote_requests_free_promo
ON quote_requests(is_free_promo) WHERE is_free_promo = true;
참고: 새 테이블 생성 없음. 기존 quote_requests에 boolean 컬럼 1개만 추가. payment_status 값에 'free_promo' 추가 (CHECK 제약조건 수정 필요 시 ALTER).

KV 저장소 (Cloudflare Workers KV)

// 프로모션 설정 (관리자가 KV로 on/off 가능)
Key: "promo:free_analysis"
Value: {
  "enabled": true,
  "max_count": 50,
  "price_display": 9900,
  "started_at": "2026-02-08T00:00:00Z"
}
KV 사용 이유: DB 쿼리 없이 프로모션 on/off 즉시 전환 가능. 50명 도달 시 enabled=false로 전환.
