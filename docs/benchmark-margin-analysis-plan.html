1 현재 문제점 (AS-IS)

문제 1: 원가 vs 견적가 직접 비교

현재 비교 방식
벤치마크 원가
50,000원/㎡
vs
견적 가격
65,000원/㎡
편차 +30% → "높음" 판정

실제로는 마진 30%가 아닌, 원가 50,000 + 적정마진(20%) = 60,000원 기준으로
편차 +8.3%로 "적정" 판정이 맞음

문제 2: 일식/총액 항목 비교 불가

현재 처리
도배 1식 250만원
벤치마크 5,000원/㎡
⚠ 단위 불일치 → 비교 스킵

면적 정보가 있으면 원가 합산 가능
(5,000원 × 110㎡ = 55만원 원가 → 마진율 355% = 과다)

문제 3: 시장가 비교 = 차별성 없음

단순 시장가 비교는 아무 인테리어 견적 사이트에서 제공.
ZipCheck의 핵심 USP인 "원가 기반 분석"을 활용 못하는 상태.

일반 사이트: 시장가 비교 ZipCheck: 원가 + 마진율 분석 ✓

문제 4: 마진율 기반 판단 부재

현재 편차%만 표시 → 사용자가 "비싼지/적정한지" 판단 기준 없음
마진율이 핵심 지표인데 노출하지 않는 상태.

사용자가 알고 싶은 것
  • "이 항목에서 업체가 얼마나 남기는 건가요?"
  • "마진이 적정 수준인가요?"
  • "어떤 항목에서 과하게 남기나요?"

3 분석 로직 흐름도 (TO-BE)

STEP 1
견적 항목 입력
카테고리 / 항목명 / 수량 / 단위 / 단가 / 총액
STEP 2
항목 유형 분류
A. 단가 비교 가능
단위가 일치 (㎡, 개, m 등) + 수량 명확
① 원가 조회: benchmark_prices → 50,000원/㎡
② 보정 적용: × 지역 × 시기 × 면적 = 52,000원/㎡
③ 마진율: (65,000 - 52,000) / 52,000 = 25%
④ 판정: 약간 높음 (적정: 15~25%)
B. 총액(일식) 항목
단위=식/일식, 수량 없음, 총액만 존재
① 카테고리 원가 합산: 해당 카테고리 대표 항목들의 원가 합산
② 면적 반영: 원가단가 × 면적(㎡) = 카테고리 원가 총액
③ 마진율: (견적총액 - 원가총액) / 원가총액 = X%
④ 판정: 동일한 마진율 기준 적용
STEP 3
마진율 기반 스코어링
카테고리별 평균 마진율 → 가중 합산 → 보너스/패널티 → 최종 점수(0~100)

5 총액(일식) 항목 분석 방법

카테고리별 기준 원가 산출 (면적 기반)

면적 정보(평형)가 있을 때, 카테고리별 대표 원가 항목의 합산으로 "이 카테고리 원가 총액"을 추정합니다.

예시: 33평(109㎡) 아파트 — 도배 카테고리
벽면 도배 원가
실크 6,000원/㎡ × 벽면적 200㎡
= 120만원
천장 도배 원가
합지 4,000원/㎡ × 바닥면적 109㎡
= 44만원
도배 철거 원가
5,000원/㎡ × 벽면적 200㎡
= 100만원
카테고리 원가 합산 264만원
견적 총액: 350만원 마진율: (350-264)/264 = 32.6% 약간 높음
적정가 범위: 304~330만원 (마진 15~25%)

면적 정보 없는 경우

면적이 입력되지 않은 경우, 총액 기반 마진율 분석 불가 →
"면적 정보를 입력하면 더 정확한 분석이 가능합니다" 안내 메시지 표시

6 카테고리별 면적 환산 계수

전용면적(㎡) 기준으로 각 카테고리의 시공 면적을 환산하는 계수. 벽면적은 바닥면적의 약 1.8~2.0배.

카테고리 시공 면적 환산 대표 원가 항목 비고
도배 벽: 전용×1.8 / 천장: 전용×1.0 실크도배 + 천장도배 등급별 벽지 단가 반영
바닥 전용면적 × 0.85 강마루/강화마루/타일 욕실·발코니 제외
페인트 벽: 전용×1.8 / 천장: 전용×1.0 벽면+천장 페인트 도배 대신 사용 시
철거 전용면적 × 1.0 (바닥) + 벽×0.5 바닥+도배+마루 철거 폐기물 별도
욕실 개수 기반 (1~2개) 타일+위생도기+수전+방수 면적 무관, 세트가
주방 싱크대 길이 (보통 2.5~3.5m) 상/하부장+상판+후드 길이 기반 또는 세트가
전기 개수 기반 (방 수 × 3~5개) 콘센트+스위치+조명+분전반 방 수 추정 가능
목공 문 개수 + 몰딩 m + 천장㎡ 문틀+몰딩+걸레받이+천장 복합 산출
가구 개수 기반 붙박이장+신발장 세트가
창호 개수 기반 (방 수 × 1~2개) 시스템창호+방문+현관문 세트가

9 구현 순서

1
auto-analysis.ts 마진율 계산 로직 추가
기존 deviation 계산 → margin_rate 계산으로 변환
단가 비교: margin_rate = (견적단가 - 보정원가) / 보정원가 × 100
총액 비교: margin_rate = (견적총액 - 추정원가총액) / 추정원가총액 × 100
2
category_cost_profiles 데이터 구성
10개 카테고리 × 4개 등급의 면적 환산 계수 + 대표 항목 정의
일식 항목의 원가 총액 추정에 사용
3
스코어링 로직 수정
기존 편차% 기반 → 마진율 기반 스코어 매핑
적정(15~25%) = 감점 없음, 과다(40%+) = 감점, 덤핑(<5%) = 감점
4
프론트엔드 UI 업데이트
종합 카드: 추정 원가 + 평균 마진율 + 적정가 범위 바
카테고리별: 마진율 바 차트 (신규 섹션)
항목별 테이블: 원가/적정가/마진율 컬럼 추가
협상 스크립트: 원가 근거 포함
5
기존 테스트 케이스 (김현우 견적서) 검증
